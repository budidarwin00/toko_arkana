# 💰 Cash Management Web Application (Uang Kas Area EF)

A modern, interactive, and real-time cash management application built with HTML5, Tailwind CSS, JavaScript (ES6), and Firebase.

## ✨ Fitur Utama (Features)

- 🔒 **Role Access Control (Authentication)**:
  - **Anggota (Member)**: Mode Read-Only (hanya dapat melihat data transaksi, saldo, daftar anggota, dan rekening bank).
  - **Admin**: Akses penuh untuk Tambah, Edit, dan Hapus (CRUD) transaksi, anggota, dan rekening bank, serta mengubah judul header aplikasi.
- 🔄 **Real-time Data Sync**: Data otomatis ter-update secara *real-time* di seluruh perangkat (HP/Laptop) anggota tanpa Perlu refresh.
- 📋 **Manajemen Rekening Bank**: Fitur tombol **Copy** 1-klik untuk nomor rekening BCA, Mandiri, dll.
- ⚡ **Otomatisasi Input**: Saat input transaksi dengan kategori **"Iuran Bulanan"**, nominal otomatis terisi Rp 100.000 dan tipe transaksi otomatis diatur ke **Pemasukan**.
- 🔠 **Urutan Anggota Otomatis**: Daftar anggota tersusun secara alfabetis secara otomatis (Aaf, Aditya, Anah, Anisa, Arief, Budi, Dozen, Heru, Nia, Putri, Supriyadi, Syarif, Topik, Yudi, Zaelani).
- 🎨 **Interaktif & Responsif**: Tampilan antarmuka modern berbasis Tailwind CSS yang responsif di HP dan Laptop.
